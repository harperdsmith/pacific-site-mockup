YOUR LAND

The pod lands on land you already own and runs on a connection that already exists. It can be set up as a non-permanent structure, and when the main build is ready it leaves on the same truck it arrived on.

THE WHOLE MACHINE

Each pod has one customer and runs as single-tenant bare metal, so you get the whole machine. Operating access down to BIOS, BMC, firmware and the fabric manager can be granted in the contract. Day to day the pod is run remotely, with contracted field service in your region.

OURS OR YOURS

Pacific's GPUs run as a managed cluster, or your own GPUs sit in a Pacific pod with power and cooling already built in. Either way you are the only tenant.
